SAR ADC IDEAL CAL REPLACEMENT V6.6 - STATIC CHECK
===================================================

Directory structure:
  src/    - core Verilog-A modules
  sim/    - simulation models and top-level netlist

  ext/    - extended calibration version
  doc/    - documentation

Core modules (src/):
  SWITCH_CAL.va: CDAC switch array, weights 2048/1024/512/256/256R/128/48/32/20/12/8/4/2
  SAR_LOGIC_0716.va: 14-tap non-binary SAR logic
  SYNC_asnyc.va: timing generator
  COM_ideal.va: ideal comparator with dither (DITHER_PAIR_EDGES=16)
  DEC_CAL_PHY.va: V6.6 calibration engine + decoder
    V6.6: 7-bit calDAC (stages 6-12), fine range ±122 LSB, SAR 7 steps
          + W5 (128) coarse auto-ranging → extended range ±250 LSB
          3-target recursive calibration: W2 -> W1 -> W0
          External anchor channel: ANCHOR_W3_LSB + ANCHOR_W4_LSB
            - Default A34=512 (nominal gauge, |e3+e4| < ~1% via layout)
            - User-supplied A34=W3+W4 physically characterized (§7 Sol. A)
              eliminates E propagation completely
          E propagates as (-E, -2E, -4E) by default (V6.3 compat);
            with external anchor (e_REF=E), residual = 0 (Theorem 6).
          W5 coarse autoranging: first k=0 probe; if saturated, select
            k=+1 (R positive overflow, subtract W5) or k=-1 (R negative
            overflow, add W5); discard probe and earlier samples;
            remeasure with R_fine = R - k*W5, restore R = (D+ - D-) + k*W5
          Per-pair saturation counting (reject if > MAX_SAT_PAIR_PCT%
            of pairs); saturated pairs excluded from accum and from the
            residual divisor (valid_pair_count).
          REJECT is fail-fast: cal_error_i=1 immediately, top weights
            revert to nominal at handoff; normal decoder falls back to
            nominal weights when ERR=1 (P1-4 fail policy).
          Single RST1-rising handler: direction-finish runs FIRST,
            handoff is an independent if (not else-if), so DONE fires on
            the SAME RST1 edge (no extra-frame delay).
          wall_weight_q initialized in initial_step (CAL_RST=0 at t=0 safe)
          REMOVE_REDUNDANCY_OFFSET honored (gates offset removal, default 1)

Version history:
  V6:   3-target (w2, w1, w0), 7-bit calDAC, ±126 range.
        Issue: E=e3+e4 propagates as -E into w2/w1/w0.
  V6.1: 4-target (+ w3+w4 joint). E propagation reduced to 1/1/1x.
  V6.2: + w2 re-correction + saturation flag.
        DEFECT (user-identified): w2 re-correction is mathematically
        invalid. Reciprocal measurement W34-W2 with digital wall =
        measured w2 yields measured = 512 identically, so the correction
        is a no-op. W2 and W34 are not separately identifiable.
        Other P0 bugs: wall_weight_q uninitialized at t=0, two RST1
        handlers cause DONE delay, REJECT silently continues, saturate_flag
        too sensitive.
  V6.3: This version. Fixes V6.2 identifiability bug and all P0 issues.
        - Removed joint target (target_idx=2). Back to 3-target.
        - W3+W4 = 512 as IMPLICIT GAUGE (layout matching).
        - W1, W0 are EXACT under gauge (E auto-cancels in recursive wall).
        - W2 has residual -E (bounded by |e3+e4| from layout).
        - wall_weight_q initialized in initial_step (P0-a fixed).
        - Single RST1-rising handler (P0-b fixed).
        - REJECT sets cal_degraded_i; ERR=1 at finish (P0-c fixed).
        - saturate_count + SAT_RATIO_PCT threshold (P0-d fixed).
        - Dead parameters removed (P0-e fixed).

  V6.3 3-round independent review fixes:
    Round 1:
      - RTL adc_code 12-bit overflow: added integer adc_code_int wide
        temp, compute and clip in integer, then narrow to 12-bit.
      - Removed dead variables cal_armed_i, valid_pair_count.
      - RTL adc_code_int initialized in initial block (R2-42).
    Round 2:
      - R2-4/R2-40: VA WEIGHT_TOL (real 0.35) → WEIGHT_TOL_PCT (integer 35),
        3 tolerance comparisons changed to integer-exact
        (measured_weight_q * 100 vs N*q_scale*(100 ± WEIGHT_TOL_PCT)),
        matching RTL.
      - R2-46: RTL redundancy_offset_q and residual_q changed from >> to /
        to match VA semantics for negative dividends (>> is arithmetic
        shift toward -inf; / rounds toward zero like C and the VA).
      - R2-A: RTL CMP_SWAP flip was unconditional, corrupting the held
        cmp_p_gt_n when COMP==COMN (no update). Fixed to flip only on a
        real update.
    Round 3:
      - R3-A: Documented that RTL omits the VA invalid_count / MAX_INVALID
        / ZERO_ON_INVALID_PHASE0 path. RTL assumes digital comparator
        always produces valid 1-of-2 output (COMP^COMN == 1) on CAL_CLK
        negedge. If the upstream comparator can be invalid, an equivalent
        guard must be added externally.
      - R3-N: Removed dead parameter REMOVE_REDUNDANCY_OFFSET (declared in
        both VA and RTL but never gated any logic; redundancy offset
        removal is always-on).

  V6.3 user-driven P0/P1 review fixes (current round):
    P0-1 (math derivation sign error):
      - Earlier V6.3 claimed "w1/w0 exact under gauge" with E auto-cancelling.
      - User-identified sign error: R1 = W1 - (W2 + W34_phys) = e1 - e2 - E
        (NOT +E), because W34_phys = 512 + E is SUBTRACTED.
      - Actual propagation: w2 = 512 + (e2 - E), w1 = 1024 + e1 - 2E,
        w0 = 2048 + e0 - 4E. E accumulates as (-E, -2E, -4E), NOT cancels.
      - V6.3 does NOT improve E propagation over V6. The improvement vs
        V6.2 is only removing the no-op w2 re-correction + fixing P0 bugs.
      - Updated: doc/PROOF_V6_3_IDENTIFIABILITY.md §4 (定理 4 更正版 + §4.5
        V6 对比 + §4.6 INL 分析), VA/RTL header comments.
    P0-2 (RST1 same-edge handoff):
      - Previous structure: if (finish_pending_i) handoff; else if
        (CAL_FINISH_DIR) direction_finish. Last target set
        finish_pending_i=1 inside direction_finish, but handoff if had
        already executed, requiring an extra RST1 edge for DONE.
      - Fix: direction_finish runs FIRST (guarded by !finish_pending_i),
        then handoff runs as an INDEPENDENT if (NOT else-if) so it can
        observe the freshly-set finish_pending_i on the SAME RST1 edge.
      - Applied to both VA (DEC_CAL_PHY.va) and RTL (DEC_CAL_PHY_rtl.v).
    P1-1 (saturate_count was per-direction, not per-pair):
      - Old code incremented saturate_count on EACH D+ and D- endpoint
        hit, so max was 2*avg_pairs. Threshold compare used avg_pairs as
        denominator, so SAT_RATIO_PCT=50 with avg_pairs=32 rejected at
        17/64 = 26.6% (not 50% as documented).
      - Fix: per-pair OR evaluated at D- completion
        (pair_saturated = d_plus_saturated || (d_minus_code endpoint?)).
        Each pair contributes at most 1 to saturate_count. Range now
        [0..avg_pairs], threshold compare is honest.
    P1-2 (saturated samples still entered the average):
      - Old code unconditionally did accum_d_plus += d_plus_code and
        accum_d_minus += d_minus_code. Even below the SAT_RATIO_PCT
        threshold, a few endpoint-clamped codes would bias residual_q.
      - Fix: if pair_saturated, skip the accum update and increment
        saturate_count instead. Use valid_pair_count (non-saturated
        pairs) as the divisor for residual_q. If valid_pair_count == 0
        (all pairs saturated), reject the target unconditionally.
    P1-3 (REMOVE_REDUNDANCY_OFFSET):
      - Confirmed: parameter was declared but never gated any logic in
        VA or RTL. Already removed in R3-N. No further action needed.
    P1-4 (degraded fail policy inconsistent):
      - File header said "downstream targets skipped" but implementation
        ran them with nominal weights. Decoder applied partial calibrated
        weights even when ERR=1, so "caller can decide" was not honest.
      - Fix: unified policy — downstream targets of a rejected target
        still run (so calibration completes), but the normal decoder
        gates calibrated weight application on (APPLY_CAL_WEIGHT != 0)
        && (cal_error_i == 0). When ERR=1 (degraded or hard error), the
        decoder falls back to nominal weights. ERR=1 now actually means
        "decoder is using nominal weights, not partial".

  V7:   DEFECTIVE (128>126 violates offset-binary SAR convergence, do not use)

V6.6 review-specific changes (this round):
  - Inherited V6.5 W5 coarse autoranging: first k=0 probe; if saturated,
    select k=+1 (R positive overflow) or k=-1 (R negative overflow);
    discard probe and earlier samples; remeasure with R_fine = R - k*W5;
    restore R = (D+ - D-) + k*W5 in residual_q.
  - Inherited V6.5 ANCHOR_W3_LSB/ANCHOR_W4_LSB external reference channel
    (§7 Solution A engineering realization). Defaults A34=512 = V6.3 compat.
  - Updated REJECT semantics from V6.3's "degraded flag → ERR=1 at finish"
    to V6.6's "fail-fast: cal_error_i=1 immediately + finish_pending_i=1".
    Rationale: recursive downstream measurements are not valid after an
    upstream rejection; V6.3's "continue with nominal weights" was
    misleading because the recursive wall still used the rejected
    measured_weight_q.
  - REMOVE_REDUNDANCY_OFFSET: V6.3 deleted this as dead; V6.5 actually
    GATES the offset removal (line 866 of V6.6 RTL). V6.6 honors V6.5's
    gating with default 1 (offset removal on, backward compatible).
  - MAX_SAT_PAIR_PCT default reduced from V6.3's 50% to 25%. Justification:
    with autoranger handling gross range issues, remaining saturation
    indicates real measurement quality problems (comparator noise, R
    near autoranger edge). 25% gives earlier warning.
  - Per-direction saturation tracking (d_plus_saturated, d_minus_saturated)
    retained; per-pair OR evaluated at D- completion. Saturated pairs
    excluded from accum_d_plus/accum_d_minus.

Known limitations (fundamental, not fixable without hardware changes):
  W5 (128) not calibrated: proven unmeasurable (Theorem 2 in PROOF doc)
    - Only wall candidate is W13=1, but |W5 - 1| = 127 > 126 calDAC range
    - V6.6 uses W5 as fixed coarse recentering cap (assumed ideal,
      |e5| < 1% via layout matching)
    - Hardware fix: split W5 into 64+64, or add external V_ref capacitor
  W3 vs W4 not separable: only W3+W4=512 gauge is assumed (default)
    - V6.6 exposes ANCHOR_W3_LSB/ANCHOR_W4_LSB to override with
      physically characterized W3/W4 (§7 Solution A). Setting
      A34=W3+W4_phys eliminates E propagation (定理 6, 推论 6.1).
    - e3-e4 differential mismatch remains as DNL noise (no fix)
  Common-mode gain error invisible: proven (Theorem 3 in PROOF doc)
    - All walls are differential, (1+alpha) scaling cancels in R
    - Requires external V_ref calibration or digital gain correction
  E propagation (default anchor A34=512): (-E, -2E, -4E) — 定理 4 更正版
    - V6.6 with default anchor = V6.3 behavior (定理 6 推论 6.2)
    - V6.6 with external anchor (A34=W3+W4_phys): E eliminated (定理 6 推论 6.1)
    - To eliminate E without external anchor: physical E=0 (|E|<0.1% layout)
  ±250 range limit (V6.6, extended from ±122 via W5 autoranging):
    - ±5% MSB mismatch in worst direction: |R0|=179.2 ≤ 250, OK
    - ±7% worst direction: |R0|=250.9, near edge, may fail
    - ±10% worst direction: |R0|=358.4 > 250, FAILS
    - To cover ±10%: need ±359 LSB (add W4=256 as 2nd coarse cap, etc.)
    - Saturated pairs after recentering excluded from accum and divisor
