# 12-bit SAR ADC 项目优化策略

> 日期：2026-05-13  
> 当前建议口径：12-bit 10-MS/s SAR ADC with CAAZ  
> 适用阶段：前仿数据收敛、论文整理、流片前风险闭环

## 1. 总体策略

当前项目不建议直接进入“极限优化”或“立即流片”模式。更合适的策略是：

**先冻结规格和数据口径，再保性能，后降功耗，最后做鲁棒性和版图闭环。**

项目目前的优势是 CAAZ 机制已经有较完整的仿真数据支撑，NF=1 与 NF=10 两组数据能够分别说明基线性能和噪声抑制能力。主要短板不在核心想法，而在规格口径、数据一致性、数字可靠性、后仿和流片验证尚未闭合。

## 2. Golden Baseline

建议先冻结以下版本作为后续所有优化的比较基准：

| 项目 | 建议基准 |
|---|---|
| 设计目标 | 12-bit 10-MS/s SAR ADC |
| CAAZ 方案 | 电流域 kT/C 噪声消除 |
| 工艺 | TSMC 18RF |
| td | 26 ns |
| NF=1 用途 | 仿真基线性能 |
| NF=10 用途 | CAAZ 噪声抑制能力验证 |
| TT ENOB | 11.61 bit |
| TT SNR | 71.81 dB |
| TT SFDR | 84.01 dB |
| TT Power | 720 uW |
| TT CAAZ eta | 87.9% |

所有后续改动都应和这个 baseline 比较，避免不同报告、不同导出批次、不同参数组合之间互相混用。

## 3. 优化优先级

### P0：规格和数据一致性

这一步优先级最高，因为它决定项目是否可信。

- 统一 `50 MS/s`、`10 MS/s`、`7.7 MS/s` 三种速率口径。
- 检查论文、MOC、研究报告、IP 规格、实验报告中的采样率表述。
- 修正论文 performance comparison 表格中仍出现的 `50 MS/s`。
- 对齐 SWITCHPOWER 的 Calculator 表达式，解释或消除约 15% 的跨批次偏差。
- 复查 FF 角 SFDR 跨批次下降约 3.5 dB 的原因。
- 将旧版 `STATUS.md`、旧版 CAAZ 分析和旧 IP spec 标记为 obsolete，或更新到当前数据口径。

验收标准：

- 所有核心文档中的速率口径一致。
- 功耗表可以追溯到同一套 Calculator 表达式。
- 论文中没有明显 placeholder、undefined citation、undefined reference。

### P1：性能余量保持

当前 ENOB、SNR、SFDR 已经达到比较好的水平，因此不要先牺牲性能去追低功耗。优先保住下面的底线：

| 指标 | 建议底线 |
|---|---|
| TT ENOB | >= 11.5 bit |
| all-corner ENOB | >= 11.4 bit |
| TT SNR | >= 71 dB |
| TT SFDR | >= 80 dB |
| TT CAAZ eta | >= 85% |
| worst-corner eta | 尽量拉到 85% 附近 |

重点关注 SF 85 degC 角。目前该角的 CAAZ eta 约 79.7%，是全角落中最弱的一点。如果论文目标只强调 TT eta，可作为 PVT 退化说明；如果目标是 all-corner eta >85%，则必须继续优化。

建议扫描：

| 参数 | 扫描点 |
|---|---|
| td | 26 / 27 / 28 / 30 ns |
| preamp gm 或 bias current | nominal / +5% / +10% / +15% |
| CAAZ switch timing | nominal / small lead / small lag |

验收标准：

- SF 85 degC 下 eta 明显改善，且 ENOB 和 SFDR 不明显退化。
- td 或 gm 的调整能够解释为电路机制，而不是单点巧合。

### P2：功耗优化

功耗优化应放在性能余量稳定之后。当前最值得优化的是 preamp，因为 PREWOCM 占比较高。

建议做 preamp current sweep：

| 方案 | 目标 |
|---|---|
| -5% current | 检查性能是否完全保持 |
| -10% current | 观察 ENOB/SNR/eta 边界 |
| -15% current | 判断是否进入明显退化区 |
| -20% current | 仅作为探索点，不建议默认采用 |

建议阶段目标：

- 第一阶段：总功耗从约 720 uW 降到约 650 uW。
- 第二阶段：如果余量充分，再尝试接近 600 uW。
- 不建议为了节省几十 uW，明显牺牲 CAAZ eta、SFDR 或 PVT 稳定性。

验收标准：

- TT ENOB 保持 >= 11.5 bit。
- all-corner ENOB 保持 >= 11.4 bit。
- TT eta 保持 >= 85%。
- 功耗下降有明确来源，不能只来自统计或导出误差。

### P3：鲁棒性和流片闭环

这一阶段决定项目能否从“论文仿真结果”进入“可流片设计”。

必须补齐的验证：

- MC mismatch。
- process MC。
- INL/DNL ramp 仿真。
- PSRR/CMRR。
- comparator noise breakdown。
- PSS/PNOISE 或等效噪声折叠分析。
- 温度 sweep，而不仅是单点 PVT corner。
- PEX 后重新验证 ENOB、SNR、SFDR、eta 和 power。

必须处理的电路与版图风险：

- DFF 动态节点需要 keeper，或给出保持裕量证明。
- CCLK fanout 需要受控 buffer tree 或 H-tree。
- SET<12> race 需要 guardband。
- ST<0> 双向节点需要重新检查。
- MOM 5 fF 单位电容需要 PEX 标定。
- 如果 PDK 没有可靠 MOM mismatch model，需要使用保守模型或设计 test structure。

验收标准：

- PEX 后主指标仍满足 baseline 底线。
- DRC/LVS/antenna/EMIR 没有未解释风险。
- 顶层 pinout、ESD、bias、VREF、VCM、POR、test mode 都有明确实现方案。

## 4. 推荐执行路线

建议按以下顺序推进：

1. 统一项目规格：确定最终采样率口径，优先采用 10 MS/s。
2. 修正论文和报告中的速率、功耗、参考文献和 placeholder。
3. 对齐 SWITCHPOWER 表达式，重新生成统一功耗表。
4. 复查 FF 角 SFDR 异常和 SF 85 degC eta 弱点。
5. 以 td=26 ns 为 baseline，做 SF 角 td/gm/timing sweep。
6. 在性能稳定后做 preamp current sweep。
7. 补 MC、INL/DNL、PSRR/CMRR、noise breakdown。
8. 启动 CDAC、CAAZ comparator、switch matrix 和 SAR logic 的版图闭环。
9. 完成 PEX 后重新生成论文表格和流片评审材料。

## 5. 当前阶段结论

当前项目已经具备较强的研究和论文基础，但还不应被视为流片就绪。最合适的近期目标是把项目优化成：

- 数据干净；
- 规格统一；
- 指标稳定；
- 论文可信；
- 风险可追踪；
- 后续版图和流片任务清楚。

完成上述收敛后，再进入系统性的版图、PEX 和 signoff 阶段，返工风险会显著降低。
