# Huang 校准与 Omran 论文高三位失配阶段报告

## 1. 失配模型

本轮不再使用人为放大的 `1x/3x/6x/9x/12x` sigma sweep，而是采用 Omran 等人在
TCSI 2016 论文 Table II 与式 (6) 给出的 Pelgrom 模型：

`sigma(Delta C / C) = K_C / sqrt(C)`

- 垂直场 MOM：`K_C = 0.14% * sqrt(fF)`。
- 侧向场 MOM：`K_C = 0.20% * sqrt(fF)`。
- 本轮先按垂直场 MOM、4 fF 单元执行，因此单元电容相对 sigma 为 `0.07%`。
- 只对 C12/C11/C10 的 P/N 电容加入独立高斯随机失配。
- C9、CR、C8、低位子阵列和桥接电容保持最新冻结网表原值。
- 八个样本均来自同一 sigma 分布，仅随机种子 7101--7108 不同。

由 `1/sqrt(N)` 缩放得到高位权重的理论 1-sigma：

| 电容 | 单元数 | 理想权重 | 权重 1-sigma |
|---|---:|---:|---:|
| C12 | 16 | 2048 LSB | 0.3584 LSB |
| C11 | 8 | 1024 LSB | 0.2534 LSB |
| C10 | 4 | 512 LSB | 0.1792 LSB |

## 2. 仿真设置

- 实际晶体管级 CDAC 与 `COM_IAZ` 比较器。
- Huang 正负残差搜索，单对测量，`FRAC_BITS=6`。
- 不启用瞬态噪声，不注入抖动。
- 完整 ADC：`va=800m`、10 MS/s、输入相干频点 59/128、128 点 FFT。
- 仿真时长 14.1 us，保存 `OUT/SOUT/CAL/DONE/ERR`，不保存全节点。

## 3. 原实现 A/B 结果

| 样本 | 高位简单平均权重 C12/C11/C10 | Huang 权重 | 不校准 SNDR | Huang SNDR | 变化 |
|---|---|---|---:|---:|---:|
| sample01 | 2048.158 / 1023.909 / 511.820 | 2045 / 1022 / 511 | 72.916 dB | 71.519 dB | -1.397 dB |
| sample02 | 2048.410 / 1024.420 / 512.106 | 2047 / 1024 / 512 | 72.923 dB | 72.273 dB | -0.650 dB |

对应 SFDR：

- sample01：不校准 83.747 dB，Huang 82.233 dB。
- sample02：不校准 81.739 dB，Huang 81.353 dB。

两份校准均 `DONE=1、ERR=0`，因此这不是状态机超时或校准未完成。

## 4. 原实现失败机理

论文模型下的高位失配小于 1 LSB，而当前无噪声单对 Huang 搜索的有效判决粒度约为
1 LSB。以 sample01 为例，真实 C10 等效权重约 511.82 LSB，但单对搜索得到 511 LSB。
该约 -0.82 LSB 的确定性量化误差进入下一层校准墙，使 C11 进一步得到 1022 LSB，
随后传播至 C12 得到 2045 LSB。因此递归校准墙放大了最低被校准高位的量化偏差。

增加 `FRAC_BITS` 本身不能解决该问题。Q6 小数权重只有在多对比较结果出现判决多样性时
才有信息来源；完全无噪声、无抖动时，重复相同比较不会产生新的亚 LSB 信息。

## 5. 2026-07-18 结构修正

对 Huang 原文 4.17--4.19 及递推次序重新核对后，VA 做了以下修正：

1. 本轮失配作用域只有 C12/C11/C10，因此 C8、C9、CR 和低位校准 DAC 不再被重复估计。
2. 校准从 C10 开始，物理 wall 为 C9+CR；之后按 C10 -> C11 -> C12 递推。
3. 正向/反向物理 SAR 搜索和 `(D+ - D-)/2` 保持不变，没有读取隐藏真实权重。
4. 恢复 1 LSB 高位更新门限。搜索仍报告原始测量值，但测量值与标称值之差不超过
   当前校准 DAC 的一个确定性量化区间时，不把该量化码写入最终权重。
5. 不启用瞬态噪声，不注入抖动；八个样本串行运行，每次只保存 CAL/DONE/ERR。

八组修正后的短校准均在 `0.600105 us` 完成，且 `DONE=1、ERR=0`：

| 样本 | C10 原始测量 | C11 原始测量 | C12 原始测量 | 最终 C12/C11/C10 |
|---|---:|---:|---:|---|
| sample01 | 511 | 1024 | 2049 | 2048 / 1024 / 512 |
| sample02 | 512 | 1025 | 2047 | 2048 / 1024 / 512 |
| sample03 | 512 | 1024 | 2047 | 2048 / 1024 / 512 |
| sample04 | 511 | 1025 | 2047 | 2048 / 1024 / 512 |
| sample05 | 511 | 1025 | 2047 | 2048 / 1024 / 512 |
| sample06 | 512 | 1024 | 2048 | 2048 / 1024 / 512 |
| sample07 | 512 | 1024 | 2048 | 2048 / 1024 / 512 |
| sample08 | 512 | 1024 | 2048 | 2048 / 1024 / 512 |

这里的“保持标称”不是声称失配为零，而是承认本电路在无噪声重复条件下不能从
`-1/0/+1 LSB` 量化码中可靠提取 0.1--0.4 LSB 的真实失配。

## 6. 准确权重上限对照

为判断 72.9 dB 是否由权重不准造成，对 sample01 额外构造了诊断专用 oracle：将
P/N 高位电容算术平均值量化到 Q6，得到约
`2048.15625 / 1023.90625 / 511.8125`。该权重不是校准输出，只用于上限判断。

| sample01 解码权重 | SNDR | SFDR | SNR | THD |
|---|---:|---:|---:|---:|
| 标称/不校准 | 72.9159 dB | 83.7470 dB | 73.6466 dB | -81.0163 dB |
| Q6 近似真实权重 oracle | 72.9159 dB | 83.7470 dB | 73.6466 dB | -81.0163 dB |

两组 128 个输出样本及频谱指标完全相同。这证明在本 Omran sample01 中，高三位失配
小到尚未改变最终 12 位输出码；即使把权重精确到 1/64 LSB，也不能把当前测试条件下的
SNDR 从 72.9159 dB 提高到 73 dB。

## 7. 阶段结论

1. Omran 垂直 MOM、4 fF 单元所预测的高位随机失配只有约 0.18--0.36 LSB rms；当前
   可切换最小物理电容对应 2 LSB，正负配对后仍只有约 1 LSB 的确定性权重分辨率。
2. 原 VA 的 2045/1022/511 不是实际电容权重，而是无噪声量化误差沿递归 wall 传播。
3. 修正后八组均完成物理 Huang 搜索，并通过 1 LSB 可信度门限避免错误更新。
4. sample01 oracle 证明 72.9159 dB 是当前 ADC/激励/128 点 FFT 的结果，不是高位权重
   校准误差；因此“所有样本校准到 73 dB 以上”不能由权重校准单独保证。
5. 当前结果不否定 Huang 原论文。论文把量化噪声包含在 `xn` 中，并用 32 对/64 次转换
   平均；在完全确定性的无噪声仿真中，重复相同搜索不会生成亚 LSB 新信息。

## 8. 后续建议

在用户要求继续保持无噪声仿真的前提下，建议把 1 LSB 门限作为本阵列的正式策略：
Huang 搜索用于检测大于当前分辨率的高位误差，小于门限时保留标称权重。下一轮应先对
大于 1 LSB、但仍由 Omran 模型合法产生的统计尾部样本验证“检测并更新”路径，再运行
完整 FFT。若必须验证论文的亚 LSB 平均收敛，则需要单独获得许可，只在校准窗口启用
真实比较器瞬态噪声；正常转换和 FFT 仍保持无噪声。
