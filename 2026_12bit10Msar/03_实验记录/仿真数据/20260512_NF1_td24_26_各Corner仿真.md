# 20260512_NF1_td24_26_各Corner仿真

## 实验条件

### 基本信息
- **日期：** 2026-05-12
- **仿真器：** Spectre 231 (APS), 64-bit
- **设计：** `test_12bit50MSAR_AMS_final` (TSMC 18RF)
- **数据源：** 本地 `仿真数据/20260512_NF1.csv`

### 噪声配置
| 参数 | 值 |
|------|-----|
| Noise Factor (NF) | **1** |
| 噪声功率倍乘 | 1×（基线性能） |
| 注入开关 | I1（时钟链），I14（采样开关） |
| 对比：旧仿真 NF=10 | 100× 噪声，用于 CAAZ 效率表征 |

### 仿真参数
| 参数 | 值 |
|------|-----|
| 类型 | `tran` + `noise` |
| 时长 | 15 µs |
| 噪声使能 | I1, I14 |
| 分辨率 | 12-bit + 1 冗余 bit |
| 输入信号 | 4.765625 MHz（61/128 相干采样） |
| 输入幅度 | 890 mVpp-diff（-0.5 dBFS） |

### 工艺角定义
| 列名 | Corner | 温度 | 模型 | 说明 |
|------|--------|------|------|------|
| Nominal | **TT** | 27°C | tt + tt_res + tt_mim | Typical |
| C0 | **FF** | -40°C | ff + ff_res + ff_mim | Fast NMOS/PMOS |
| C1 | **SS** | 85°C | ss + ss_res + ss_mim | Slow NMOS/PMOS |
| sf | **SF** | 85°C | sf + ss_res + ss_mim | Slow NMOS, Fast PMOS |
| fs | **FS** | -40°C | fs + ss_res + ss_mim | Fast NMOS, Slow PMOS |

### 时序配置
两段 CAAZ 建立时间 td，覆盖 10 个仿真点：

| td 设置 | 点编号 | Corners |
|---------|--------|---------|
| **24.05 ns** | 1–5 | TT / FF / SS / SF / FS |
| **26.0 ns** | 6–10 | TT / FF / SS / SF / FS |

## 要点

1. **NF=1 基线性能：** 全 corners ENOB > 11 bit，TT@26ns 最佳 11.61 bit / 71.81 dB
2. **td=26ns 全面优于 td=24ns**，ENOB 高 0.1–0.4 bit，SS 和 SF 改善最明显
3. **最差情况：** SF (85°C) 在 td=24ns 时 ENOB=11.24，功耗最高 508 µW
4. **与旧仿真（NF=10）无可比性：** SNR 差距 ~16 dB 完全是噪声注入差异导致
5. **SFDR 裕量充足：** 最低 77 dB，大部分 corners > 80 dB
