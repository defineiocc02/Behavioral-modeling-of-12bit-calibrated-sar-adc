## 文件命名规范

### 格式

```
YYYYMMDD_{关键条件1}_{关键条件2}_各Corner仿真.md
```

### 字段说明

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `YYYYMMDD` | ✅ | 仿真导出日期 | `20260512` |
| `{关键条件}` | ✅ | 与基准不同的关键参数，用下划线分隔 | `NF1`, `td24_26`, `td26` |
| `各Corner仿真` | ✅ | 固定后缀 | `各Corner仿真` |

### 命名示例

```
20260512_NF1_td24_26_各Corner仿真.md    → NF=1, td=24ns和26ns
20260512_NF10_td26_各Corner仿真.md       → NF=10, td=26ns
20260513_NF10_td26_27C_各Corner仿真.md   → NF=10, td=26ns, 仅27°C
```

### 规则

1. 日期使用导出 CSV 的日期（非仿真开始/结束日期）
2. 关键条件按重要性排序：`NF` 优先于 `td` 优先于温度
3. 多项条件用下划线连接，不使用特殊字符
4. 文件名全英文（数字和下划线除外）

## 文件内容规范

每个数据文件必须遵循以下结构：

### 1. 标题行

```
# YYYYMMDD_关键条件_各Corner仿真
```

### 2. 实验条件（必须放在数据之前）

| 区块 | 内容 | 说明 |
|------|------|------|
| 基本信息 | 日期、仿真器、设计名、本地数据源路径 | 必填 |
| 噪声配置 | NF、噪声功率倍乘、注入开关 | 必填 |
| 仿真参数 | 类型、时长、输入信号、采样率 | 必填 |
| 工艺角定义 | 各列对应的 Corner/温度/模型 | 必填 |
| 时序配置 | td 值、每组覆盖的编号 | 必填 |

### 3. 数据表格

以 td 分组，每组包含：
- **动态指标：** ENOB, SNR, SFDR
- **功耗分解：** COMPOWER（含PREWOCM+SRPOWER+驱动器）, SWITCHPOWER, LOGICPOWER, SYNCPOWER
- **总功耗：** 模拟 = COMPOWER + SWITCHESPOWER，数字 = LOGICPOWER + SYNCPOWER

### 4. 要点总结

列出关键结论和异常点。

### 5. 待补充

记录后续计划。

## CSV 源数据管理

CSV 统一拉取到本地，与 `.md` 解读文件放同一目录。命名与对应 `.md` 文件一致。

```
仿真数据/
├── 存放规范.md
├── 20260512_NF1.csv             ← 原始 CSV
└── 20260512_NF1_td24_26_各Corner仿真.md  ← 解读文件
```

每次新仿真导出后：
1. `scp` 从 VM 拉取 CSV 到本地：`scp meow@192.168.38.128:/home/meow/jxy/simulation/ExplorerRun.0.csv ./YYYYMMDD_NF{val}.csv`
2. 在本文件夹创建对应的 `.md` 解读文件
