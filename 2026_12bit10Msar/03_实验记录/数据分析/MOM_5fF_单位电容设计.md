# MOM 5 fF 单位电容设计方案

> 用于 12-bit 50MS/s SAR ADC CDAC，TSMC 18RF
> 小 C_CDAC → 大 kT/C → CAAZ 噪声消除效果更显著

---

## 一、结构设计

### 1.1 方案：M4-M5 叉指 + M2-M3 屏蔽

选用顶层金属 **M4 + M5** 堆叠（via 连接），最大化单位长度耦合电容。下层 **M2-M3** 作接地屏蔽，减少衬底串扰。

```
俯视图（M4-M5 stacked）：

  ┌─────────────────────────┐  ← 屏蔽环 (M4-M5, 接AC GND)
  │  ──  ──  ──  ──  ──  │  Plate A (M4-M5 stacked)
  │    ──  ──  ──  ──  ──  │  Plate B (M4-M5 stacked)
  │  ──  ──  ──  ──  ──  │  Plate A
  │    ──  ──  ──  ──  ──  │  Plate B
  └─────────────────────────┘
```

```
剖视（横向）：

  Plate A  ═══╗     ╔═══  Plate B
              ║  ║
  M5  ────────╫──╫────────  ← thick metal
       │  │  ││  ││  │  │
       ║  ║  ║║  ║║  ║  ║
  M4  ─╫──╫──╫╫──╫╫──╫──╫─
       ║  ║  ║║  ║║  ║  ║
       │  │  ││  ││  │  │
       ──────────────────
  M3  ████████████████████  ← 屏蔽层 (AC GND)
  M2  ████████████████████  ← 屏蔽层 (AC GND)
```

### 1.2 几何参数

| 参数 | 值 | 依据 |
|------|-----|------|
| 叉指宽度 W | **0.28 µm** | M5 最小宽度 |
| 叉指间距 S | **0.28 µm** | M5 最小间距 |
| 叉指长度 L | **3.2 µm** | 耦合长度 |
| 指对数 N | **8** | 每侧 8 根，共 16 根 |
| 使用层次 | **M4 + M5** | via 阵列堆叠 |
| 屏蔽层次 | **M2 + M3** | 接 AC GND |
| 屏蔽环宽度 | 0.5 µm | 包围整个单元 |
| **单元尺寸** | **~5.8 × 5.8 µm** | 含屏蔽环 |

### 1.3 预期电容值

单位长度耦合电容（M4+M5 堆叠，双侧耦合）：**~0.17 fF/µm** 每指

```
C_total ≈ N × 2 × L × 0.17 fF/µm
        = 8 × 2 × 3.2 × 0.17
        ≈ 8.7 fF  —— 偏大
```

**需通过 PEX 标定调整**：先按 8 叉指 3.2 µm 画出，PEX 提取后，反推实际密度，再迭代到 5 fF。

**预期最终尺寸**（5 fF 标定后）：
- 指长 L：**2.5-3.0 µm**
- 指对数 N：**6-8**
- 单元尺寸：**~5 × 5 µm**（含屏蔽环）

## 二、CDAC 阵列规划

### 2.1 阵列规模

12-bit 单端 + 1 位冗余（split CDAC 或分段）：

| 配置 | 单位电容数 | 总面积 |
|------|----------|--------|
| 全二进制 12-bit | 4096 | ~1.0 × 1.0 mm² |
| 6+6 分段 | 128 + 64 = 192 | 偏小不合理 |
| 8+4 分段 | 256 + 16 = 272 | ~0.1 × 0.7 mm² |
| **推荐：7+5 分段** | **128 + 32 = 160** | **~0.6 × 0.6 mm²** |

推荐 **7+5 分段架构**（MSB 7-bit 二进制 + LSB 5-bit 单位），配合 **attenuation cap**，总单位电容数 160 个，面积可控。

### 2.2 布局方案

```
┌─────────────────────────────────┐
│  顶部 dummy 行                    │
│  ┌──┬──┬──┬──┬──┬──┬──┬──┐    │
│  │U │U │U │U │U │U │U │U │    │ ← 8 列
│  ├──┼──┼──┼──┼──┼──┼──┼──┤    │
│  │U │U │U │U │C │C │C │C │    │ ← 中心: 控制逻辑
│  ├──┼──┼──┼──┼──┼──┼──┼──┤    │
│  │U │U │U │U │  │  │  │  │    │
│  ├──┼──┼──┼──┼──┼──┼──┼──┤    │
│  │U │U │U │U │  │  │  │  │    │
│  ├──┼──┼──┼──┼──┼──┼──┼──┤    │
│  │U │U │U │U │  │  │  │  │    │
│  ├──┼──┼──┼──┼──┼──┼──┼──┤    │
│  底部 dummy 行                    │
└─────────────────────────────────┘
```

- 全 **common-centroid** 摆放
- 周边加 2 圈 dummy unit cell（浮空或接 AC GND）
- 每列顶底加 dummy row

## 三、实现步骤

### Step 1：建立 MOM unit cell

```
1. Virtuoso CIW → File → New → Cell View
      Cell Name: mom_unit_5f
      Type: layout
2. 创建参考层次：
   - M2/M3: 整块屏蔽层（接 vss!）
   - M4: 叉指图形（A/B 两套）
   - M5: 跟 M4 完全对齐 + VIA45
   - 屏蔽环: M4/M5 外围一圈接 vss!
3. Create Instance → VIA45 → 阵列打在 M4-M5 指上
```

### Step 2：PEX 提取标定

```
1. 先用 conservative finger 数量画出第一个版本
2. Calibre PEX → 提取 C + CC
3. 读 C_total:
   - > 5 fF → 缩短指长 或 减少指对
   - < 5 fF → 加长指长 或 增加指对
4. 迭代到 5 fF ± 0.1 fF
```

### Step 3：Mismatch Monte Carlo

```
1. 复制 32 个 unit cell
2. 用 PDK 中的 mismatch model（no MC for MOM though...）
```

现实是：MOM 的 mismatch 没有 PDK 模型。你需要**后续测试估算**或**用 MIM 的 mismatch 数据按面积类推**。

对于 MIM 在 180nm 的匹配：
```
σ(ΔC/C) ≈ (A_mismatch / √(W·L))  其中 A_mismatch ≈ 1-2%·µm
```

MOM 因为金属工艺控制更好，匹配不会差于 MIM。

### Step 4：生成 CDAC 阵列

用 SKILL 脚本自动生成阵列版图：

```
1. 读取 layout 参数 (分段数, 单位尺寸)
2. 自动摆放 common-centroid 矩阵
3. 自动布线 + dummy
```

这一步可以用 `virtuoso-bridge-lite` 的 `skill.layout.draw_array()` 来简化。

## 四、风险评估

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 5 fF 偏大，最终尺寸无法达标 | 低 | 面积略增 | 减少指对数即可 |
| MOM 匹配不够 12-bit | 中 | ENOB 下降 | layout common-centroid + dummy 充足 |
| 寄生 RC 影响建立时间 | 低 | 速度略降 | PEX 后反标回 netlist 验证 |
| 无 mismatch model 无法 tapeout | 高 | 流片风险 | 用 MIM mismatch 数据保守外推 + test chip 上 MOM 测试结构 |

## 五、与论文的呼应

小电容策略本身就是技术亮点：

```
传统 12-bit SAR CDAC      本文 SAR with CAAZ
─────────────────       ─────────────────
单位电容 20-50 fF       单位电容 5 fF (MOM)
C_CDAC_total 80-200 pF  C_CDAC_total ~20 pF
kT/C 噪声 0.15-0.22 µV  kT/C 噪声 0.45 µV
                         ↓
                     CAAZ 消除采样噪声
                    仿真 90.8% 消除率
                     10 dB SNR 提升
```

单位电容越小 → C_CDAC 越小 → kT/C 噪声越大 → CAAZ 的 SNR 改善倍数越耀眼。这是论文中最有说服力的实验数据点之一。
