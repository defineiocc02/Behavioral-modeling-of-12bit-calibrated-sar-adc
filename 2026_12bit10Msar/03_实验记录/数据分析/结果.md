### 2.2 理论深度扩写

#### 新增小节：B. Non-ideal Effects Analysis

添加了以下关键公式和分析：

1. **不完全建立噪声**：
   ```latex
   v_{ns1,incomplete} = v_{ns1} \cdot e^{-\Delta t / \tau_{CAAZ}}
   ```
   其中 $\tau_{CAAZ} \approx \frac{C_{AZ} + C_{gs3,4}}{g_{mn}}$

2. **放大器热噪声**：
   ```latex
   \overline{v_{preamp}^2} = \frac{4kT\gamma}{g_{mp}} \cdot \frac{\Delta t}{C_{AZ}^2}
   ```

3. **噪声折叠效应**：
   ```latex
   NF_{folding} \approx 1 + \frac{BW}{f_s}
   ```

4. **漏电流漂移**：
   ```latex
   \Delta V_L = \frac{I_{Lg} \pm I_{Lsw}}{C_{AZ}} \times \frac{1-D}{f_s}
   ```

5. **共模瞬态耦合**：
   ```latex
   K_{coupling} = \frac{C_{gd3}}{C_{gd3} + C_{AZ} + C_{gs3}}
   ```

6. **动态增益失配与SFDR**：
   ```latex
   SFDR_{mismatch} \approx 20\log_{10}\left(\frac{\Delta g_{mp}}{g_{mp}}\right)
   ```

#### 新增小节：C. System-Level Energy Efficiency Analysis

添加了系统级功耗分析：

1. **外部驱动功耗**：
   ```latex
   P_{ext} = C_1 \cdot V_{DD}^2 \cdot f_s
   ```

2. **所需跨导计算**：
   ```latex
   g_{mn} \geq \frac{C_{AZ}}{\Delta t} \cdot n
   ```

3. **能效提升**：证明 $\eta > 60\%$ 功耗降低

### 5.3 Table III溢出问题（已解决）

Table III曾存在35pt溢出问题，**已使用`\resizebox`方案解决**：

```latex
\usepackage{graphicx}  % 在导言区添加

\begin{table}[!t]
\caption{Comprehensive Noise Budget Comparison}
\label{tab:noise_budget}
\centering
\resizebox{\columnwidth}{!}{%
\begin{tabular}{|l|l|l|l|}
...
\end{tabular}%
}
\end{table}
```

此方案将整个表格精准缩放到单栏宽度，美观且不会报错，比单纯缩小字体更优雅。
