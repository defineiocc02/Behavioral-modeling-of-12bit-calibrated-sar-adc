## 测量口径

- NF10 测试：仅打开采样噪声，`NOISEFACTOR=10`。
- `NOISEFACTOR=10` 表示采样噪声电压放大 10 倍，对应采样噪声功率放大 100 倍，因此采样噪声成为主导噪声分量。
- 原本基准：A 方案中 `td=24.05n`，AZ 时间约 `0.05ns`，可等效为没有充分完成采样噪声消除。
- 正式对比点：A/B/C 统一看约 `4ns` AZ 的结果。
- 最新 C 组归档时 VM 仍可见 Virtuoso/Spectre 进程；本次只读下载。RDB 内 5 个 corner 均为 done，`SRPOWER` 为 evaluation error，因此功耗分析采用有效的 `Power/COMPOWER/SWITCHESPOWER/LOGICPOWER/SYNCPOWER`。

## 核心结论

| 方案 | SNR avg / dB | Power avg / uW | 采样噪声剩余 | 采样噪声降低 |
| --- | ---: | ---: | ---: | ---: |
| A：FIA 基础电流失调 KT/C | 63.9574 | 307.8167 | 10.92% | 89.08% |
| C：电流型 KT/C 无 FIA | 64.0150 | 351.5700 | 10.78% | 89.22% |
| B：电压失调 KT/C | 66.1743 | 439.8245 | 6.55% | 93.45% |

基本判断：

1. A 到 `td=28n` 后，采样噪声功率约剩余 `10.92%`，约消除 `89.08%`。
2. C 组与 A 组非常接近，平均 SNR 只高 `0.0576 dB`，消除百分比只多约 `0.14` 个百分点。因此 C 是有效对照，不应表述为明显优于 A 的新正式方案。
3. B 组平均 SNR 最高，采样噪声功率剩余约 `6.55%`，约消除 `93.45%`，是当前三组中采样噪声压低最强的一组。
4. 功耗取舍明显：C 比 A 平均总功耗高 `43.7533 uW`；B 比 C 高 `88.2545 uW`，比 A 高 `132.0078 uW`。
