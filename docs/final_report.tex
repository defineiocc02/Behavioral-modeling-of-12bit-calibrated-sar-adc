\section{架构总览}

\subsection{系统架构}

本项目实现了一款全差分、异步 split-CDAC SAR ADC 的完整行为级模型与可综合 RTL 校准逻辑。系统包含三个核心层次：

\begin{enumerate}[nosep]
  \item \textbf{Python 行为级模型} —— 电荷守恒求解器 + P/N 独立失配 + Shen 2018 校准协议 + FFT 验证管线
  \item \textbf{可综合 RTL} —— cal\_fsm (16 态校准状态机)\\
  \hspace*{2em} + cal\_weight\_reg (权重寄存器) + sar\_subconverter (子转换 SAR)
  \item \textbf{实验套件} —— AVG\_PAIRS 扫描、Dither 消融、噪声热力图、MC 多 $\sigma$ 扫描
\end{enumerate}

\textbf{关键成本优势：}
\begin{enumerate}[nosep]
  \item \textbf{0 DSP:} 校准乘法由预计算 localparam 常量 LUT 替代（编译时计算 `NOMINAL\_Q0 $\times$ tolerance\% $\times$ 256`）
  \item \textbf{0 BRAM:} 权重寄存器为分布式寄存器（224 bit 总量）
  \item \textbf{0 除法器:} 平均除以 128 用右移 7 位替代（128 = $2^7$）
\end{enumerate}
