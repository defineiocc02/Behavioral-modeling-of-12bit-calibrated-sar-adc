\section{工程组织架构：Python、RTL、Verilog-A 与交付链}

\subsection{为什么按证据层组织，而不是按文件类型堆叠}

本项目同时包含行为模型、可综合数字逻辑和模拟行为模型。如果只把它们称作
“三种语言实现”，很容易产生两个错误：一是把 Python 的100-seed 结果当作
RTL 或电路级结果；二是同一物理机制在不同语言里悄悄漂移。本轮采用
\keyterm{职责、接口、权威边界、证据输出}四维组织：

\begin{itemize}
  \item Python 是失配、物理 decisions、校准权重和系统指标的行为级黄金链路；
  \item SystemVerilog 是前景校准控制、递归 lower-SAR 和 Q8 寄存器的可综合子集；
  \item Verilog-A 是 CDAC 电荷方程和比较器行为的 AMS 接口骨架；
  \item \code{evidence/} 是进入报告的唯一正式数据源，探索性图片不能绕过冻结流程；
  \item 文档与 CI 只消费冻结证据，不在 LaTeX 中手填统计数字。
\end{itemize}

\subsection{Python：从物理拓扑到正式验收}

\subsubsection{配置与 topology}

\code{config.py} 定义15个决策 stage、14个物理电容、参考电压、Q8 校准
权重和 Q2 输出格式。\code{topology/} 只描述元件与开关，不计算 SNDR：

\begin{itemize}
  \item \code{capacitor.py} 区分物理电容与 comparator-only terminal；
  \item \code{cdac\_topology.py} 构建 high、bridge、low 三部分，并接收 P/N
    两侧独立 realized capacitances；
  \item \code{switch\_state.py} 保存每个 bottom plate 的 rail；
  \item \code{switching\_policy.py} 生成 sampling、reset、trial 和 commit。
\end{itemize}

这一分层保证校准算法无法通过偷偷修改拓扑来“修复”失配。

\subsubsection{physical、comparator 与 async control}

\code{physical/charge\_solver.py} 对每侧求解 top/bridge 两节点矩阵，
\code{differential\_cdac.py} 组合 P/N 两侧并保留 sampled charge。
\code{comparator/dynamic\_comparator.py} 将差分顶板电压变成 polarity 与行为级
decision delay；\code{async\_control/handshake.py} 执行15-stage
trial/commit 并保存 trace。这里产生的是\keyterm{物理 decisions}，不是最终 code。

\subsubsection{calibration 与 decode}

\code{calibration/shen\_calibrator.py} 对七个高段 target 依次运行
P0/P1/N0/N1，已经校准的高段递归加入后续 lower ruler。每个 target 写回时
立即截断到 Q8，与 RTL 的算术右移一致。\code{decode/sar\_decoder.py}
再用 nominal、calibrated 或 physical-oracle P/N 权重解读同一组 decisions。

\subsubsection{validation 与 pipeline}

\code{validation/} 分成四种职责：

\begin{enumerate}
  \item \code{fft\_protocol.py} 固定 coherent FFT 和 clipping 检查；
  \item \code{reachable\_codebook.py} 做精确可达树、DNL/INL、missing 和 backstep；
  \item \code{acceptance.py} 把动态、code-density static 和 monotonic diagnostic 分开；
  \item \code{summarize\_mismatch\_matrix.py} 汇总完整 case 并写 provenance hash。
\end{enumerate}

\code{run\_final\_calibration\_pipeline.py} 是正式 orchestration：
生成 PER-UNIT mismatch、运行校准、做三路公平解码、FFT 和静态审计，
最后输出每种子 CSV、case JSON 和 manifest。\code{analysis/} 只允许探索，
其中旧图片不进入当前报告。

\subsection{Verilog-A 与跨语言接口}

\code{cdac\_behavioral.va} 是 P/N 两侧独立的两节点电荷守恒模型；
\code{strongarm\_cmp.va} 提供 polarity、offset、可选噪声、输入相关延迟和 ready。
Verilog-A 不在模块内部抽 mismatch RNG，testbench 应把 Python 同一 seed
生成的 realized group multipliers 外部传入。这样才能做到逐 stage trace 对照。

计划中的 AMS testbench 负责把 RTL 2-bit switch encoding 映射到模拟 rails，
把 comparator result/ready 接回数字控制，并保存 top/bridge waveform。
本轮缺少可用 Spectre/OpenVAF，因此该接口是\keyterm{设计完成、工具未闭环}，
不能写成已仿真。

\subsection{脚本、冻结证据、文档和 CI}

\code{run\_mismatch\_matrix.ps1} 运行五个正式 case；
\code{freeze\_mismatch\_evidence.py} 只复制完整结果；
\code{generate\_report\_metrics.py} 生成本文宏；
\code{generate\_report\_figures.py} 只读冻结 CSV/JSON。
GitHub Actions 在 Ubuntu/Python 3.12 上执行 pytest、重画 current figures 和
metrics，并上传 artifact；它不跑 Vivado、Spectre 或 XeLaTeX PDF QA。

\begin{notebox}
  这套组织的核心是“权威不能越级”：Python 证明行为级逻辑，RTL 证明可综合
  子系统，Verilog-A 证明移植方程骨架，冻结证据证明报告数据来源。任何
  transistor/layout/silicon claim 都必须新增对应层证据。
\end{notebox}

\section{验收口径、主变量与证据边界}

\subsection{主变量是失配，不是噪声}

正式矩阵把单位电容失配设为0、0.5\%和1.0\%。normal conversion 的
comparator noise 始终为0。0.3 mV RMS 只在 P0/P1/N0/N1 lower-SAR
比较时打开，用于验证失配校准是否会被量化锁定破坏。

\begin{table}[htbp]
  \centering
  \caption{五个正式 case 的目的}
  \begin{tabularx}{\textwidth}{@{}p{38mm}p{25mm}p{25mm}Y@{}}
    \toprule
    \tablehead Case & PER-UNIT $\sigma_C$ & 校准扰动 & 用途\\

\section{split-CDAC 与采样路径的底层复核}

\subsection{阵列结构}

每个差分侧采用整数单位电容：

\[
  C_H=71C_u,\qquad C_B=2C_u,\qquad C_L=65C_u,\qquad
  C_{\text{side}}=138C_u .
\]

高段为 $32,16,8,8,4,2,1$ Cu，低段为
$32,16,8,4,2,2,1$ Cu。bridge 是 top node 与 bridge node 之间的内部
串联电容，没有 bottom-plate switch。P/N 合计276 Cu。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.90\textwidth]{figures/mismatch_report/fig_cdac_topology.pdf}
  \caption{P/N 两侧完整连接。sampling 只钳位 top node 到 VCM；high/low
  bottom plates 全部接 VINP/VINN；bridge node 保持浮动。}
\end{figure}

\subsection{两节点电荷守恒}

对任一侧，转换相位使用：

\[
\begin{bmatrix}
C_H+C_B & -C_B\\
-C_B & C_L+C_B
\end{bmatrix}
\begin{bmatrix}
V_{\mathrm{TOP}}\\
V_{\mathrm{BR}}
\end{bmatrix}
=
\begin{bmatrix}
Q_{\mathrm{TOP}}+\sum C_{H,i}V_{H,i}\\
Q_{\mathrm{BR}}+\sum C_{L,i}V_{L,i}
\end{bmatrix}.
\]

Python 与 Verilog-A 都直接求解该矩阵，而不是先把 bridge 简化成固定比例。
标称有效权重为：

\[
  W_{H,\mathrm{unit}}=C_L+C_B=67\ Q0,\qquad
  W_{L,\mathrm{unit}}=C_B=2\ Q0.
\]

\subsection{采样路径为什么必须全阵列参与}

sampling 时，P 侧14个 high/low bottom plates 接 VINP，N 侧接 VINN；
仅 VTOP\_P/VTOP\_N 钳位到 VCM。bridge node 的采样电压由

\[
  V_{\mathrm{BR,sample}}
  =
  \frac{C_BV_{\mathrm{CM}}+C_LV_{\mathrm{IN}}}{C_B+C_L}
\]

决定。若再把 bridge node 强行钳到 VCM，就相当于增加了原架构不存在的模拟
开关，并破坏采样电荷。若低段不采样输入，则低段只剩校准 DAC 功能，正常转换
增益和权重都会错误。

\subsection{正常转换顺序}

14个物理 stages 从大到小 trial/commit，stage 14 是 comparator-only
terminal decision，因此每个行为级 normal conversion 共15次比较。
terminal 不增加物理电容，只提供残差舍入；理想 case 的0 missing、0 backstep
和 \IdealCalSndr{} dB SNDR 证明该链路本身没有异常。

\section{PER-UNIT 失配模型与传播}

\subsection{本轮正式采用的失配方式}

每个 unit cell 独立高斯：

\[
  C_{\mathrm{group}}
  =
  C_u\sum_{k=1}^{N}(1+\epsilon_k),
  \qquad
  \epsilon_k\sim\mathcal{N}(0,\sigma_C).
\]

因此 $N$-Cu group 的相对标准差是 $\sigma_C/\sqrt{N}$。P/N 两侧独立，
bridge 的两个 units 也独立。0.5\%和1.0\%是行为级探索值，不是 foundry
MOMCAP Monte Carlo 数字。

\begin{table}[htbp]
  \centering
  \caption{PER-UNIT 模型下 group 相对标准差}
  \begin{tabular}{@{}lccccc@{}}
    \toprule
    \tablehead Unit $\sigma$ & 1 Cu & 2 Cu & 4 Cu & 8 Cu & 16 / 32 Cu\\
    \midrule
    0.5\% & 0.500\% & 0.354\% & 0.250\% & 0.177\% & 0.125\% / 0.088\%\\
    1.0\% & 1.000\% & 0.707\% & 0.500\% & 0.354\% & 0.250\% / 0.177\%\\
    \bottomrule
  \end{tabular}
\end{table}

\subsection{为什么 flat PER-CAP 会误导}

若给1-Cu和32-Cu group施加相同相对 sigma，就隐含认为32个并联单位完全相关，
会高估大电容 group 的随机失配，并改变 target-to-target 校准难度。本轮
Python formal matrix 使用 PER-UNIT；Verilog-A 的 \code{P\_MC\_*}/
\code{N\_MC\_*} 只能接收已实现 group multiplier，testbench 不得再次按
flat group sigma 抽样。

\subsection{失配如何影响最终输出}

失配先改变 two-node matrix 的系数，再改变每个 stage 的真实差分权重。
正常 SAR decisions 由这些真实权重产生，但 nominal decoder 仍按标称 Q2
重构，于是同一 decision word 被映射到错误 code，造成 SNDR、INL 和 DNL
退化。physical-weight oracle 仍接近理想上限，说明主要问题是
\keyterm{数字重构权重与物理权重不一致}，不是阵列动态范围本身崩溃。

\section{前景校准、0.3 mV 扰动与 Q8 硬件契约}

\subsection{P0/P1/N0/N1 观测量}

对每个高段 target：

\[
\begin{aligned}
  W_P &=
  \frac{1}{2N}\sum_{j=1}^{N}\left(S_{P0,j}-S_{P1,j}\right),\\
  W_N &=
  \frac{1}{2N}\sum_{j=1}^{N}\left(S_{N1,j}-S_{N0,j}\right).
\end{aligned}
\]

顺序为 H1、H2、H4、H8-R、H8-A、H16、H32。低段加 terminal 是
131-Q0 base ruler；校准更大 target 时，已校准高段递归加入。

\subsection{0.3 mV 的准确含义}

0.3 mV RMS 是每次校准比较的输入等效高斯扰动：

\[
  n_{\mathrm{cal}}\sim\mathcal{N}\left(0,(0.3\ \mathrm{mV})^2\right).
\]

12-bit、1.8 V 下1 LSB约为0.439 mV，所以0.3 mV约0.68 LSB。它只进入
校准 comparator；normal conversion comparator noise=0，固定 dither
sequence 关闭，也没有 dither DAC。

\subsection{为什么完全零扰动会量化锁定}

同一 target、同一 force state、同一零输入下，lower-SAR 是确定性离散量化器：

\[
  S_{P0,1}=S_{P0,2}=\cdots=S_{P0,128}.
\]

重复128次不会产生额外分辨率。小幅零均值扰动让阈值附近 decisions 随机翻转，
平均后得到亚码宽权重信息。因此它是 calibration measurement decorrelation，
不是“噪声越大性能越好”的正常 ADC 结论。

\subsection{Q8 与递归一致性}

本轮修正了两个硬件一致性问题：

\begin{itemize}
  \item Python 每个 target 写回后立即截断到 Q8，后续 target 不再获得 RTL
    中不存在的 sub-Q8 精度；
  \item \code{sar\_subconverter.sv} 对已校准 high stages 读取 P/N 分侧
    Q8 register，不再在失配下错误地使用全 nominal ruler。
\end{itemize}

H32 nominal Q8 为 $2144\times256=548864$，16-bit Q8 不够；当前每项
20 bits，P/N七项合计280 register bits。24-bit signed lower sum 和
32-bit pair accumulator 保留足够符号与累加余量。

\subsection{校准工作量与纯数字 schedule}

默认参数执行：

\[
  7\times4\times128=3584
\]

个 lower-SAR subconversions，以及

\[
  4\times128\times(8+9+10+11+12+13+14)=39{,}424
\]

次 lower comparator decisions。按当前同步 RTL，TRIAL/COMMIT 每 stage
两周期，再计 SAMPLE、DONE、handshake、ACCUMULATE 和 target boundary，
纯数字 schedule 约94,115 clocks，即100 MHz下约0.941 ms。

\begin{notebox}
  0.941 ms 不含真实 CDAC/reference settling、comparator ready 和
  metastability tail。当前 RTL 固定按 clock 采样 \code{cmp\_out}，没有
  \code{ready} 输入；实际集成必须证明10 ns周期覆盖最差 PVT，或增加握手。
\end{notebox}

每个 seed 只运行一次物理 conversion 并保存15-bit decisions，随后分别使用

\subsection{FFT 协议}

\[
  N=4096,\quad k=1019,\quad A=-0.5\ \mathrm{dBFS},\quad
  \phi=0.123\ \mathrm{rad}.
\]

$k$ 与 $N$ 互质，使用 rectangular window。每个 seed 先测量可用 VFS，
再构造 coherent differential sine，并检查 peak/VFS 与 clipping。
因此不同 mismatch seed 不会因固定输入幅度越过可用范围而产生假 SNDR 尾点。

\subsection{精确可达树与静态指标}

comparator residue 对输入是仿射函数；每个 decision prefix 最多把输入区间
切分一次。遍历所有可达 leaves 后得到：

\begin{itemize}
  \item unique/missing integer codes；
  \item exact code-density DNL/INL；
  \item float/integer backsteps、最大 rollback；
  \item 所有 nonmonotonic intervals 的输入宽度和。
\end{itemize}

同一 output code 可能来自多个不相交输入区间。code-density 将这些宽度相加，
strict ordering 则保留局部输入顺序。两者回答不同问题，不能互相替代。

\subsection{正式证据冻结}

每个 case 保存 CSV、case summary 和 run manifest。working 与
\code{evidence/mismatch\_matrix/} 分别重新汇总后必须字节一致。
图和 LaTeX metrics 只读取冻结版本；这样可防止用户所担心的“图片与数据版本混乱”。

\section{专章：单调性、局部 backstep 与过度设计边界}

\subsection{必须先区分三件事}

\begin{enumerate}
  \item \textbf{Code-density DNL/INL：}按每个输出 code 占据的总输入宽度计算；
  \item \textbf{Missing code / max jump：}判断整数 code 是否完全缺失或跨越；
  \item \textbf{Strict ordering：}输入从小到大时，decoded output 是否在每个
    可达边界都不下降。
\end{enumerate}

冗余 SAR 允许不同 decision words 映射到相近甚至相同 code。同一 code 可由
多个不相交区间产生，因此 code-density 可以合并宽度并通过，而局部输入顺序
仍发生1-LSB回退。这不是计算矛盾，而是两个指标定义不同。

\subsection{产生原因}

局部 backstep 由以下因素共同产生：

\begin{itemize}
  \item redundant stage weights 使相邻 decision words 不再等价于简单二进制顺序；
  \item PER-UNIT mismatch 改变 P/N 分侧实际权重；
  \item 校准只估计七个高段，低段和 terminal 使用 nominal base ruler；
  \item Q8 权重和 Q2 输出引入有限分辨率；
  \item comparator decision boundary 与数字 weighted sum 的局部排序不必完全一致。
\end{itemize}

理想 case 为0 backstep，说明它不是 stage mapping 或 polarity 的基础 bug。
失配后出现说明这是“物理 decision partition 与有限精度 digital
reconstruction 的局部错序”，不是整个 transfer 失稳。

\subsection{它什么时候真的重要}

若 ADC 用于普通采样和频谱测量，SNDR、ENOB、missing、DNL/INL 已捕捉主要影响。
但以下应用可能把严格单调设为硬约束：

\begin{itemize}
  \item 闭环 servo、控制器或逐码搜索，要求输入上升时 code 绝不下降；
  \item threshold scanning 或 code-domain inverse mapping，需要唯一可逆顺序；
  \item 以 ADC code 直接驱动状态机、窗口比较或 safety interlock；
  \item 局部回退扩大到多 LSB 或宽输入区间，可能形成 limit cycle、局部歧义或 spurs。
\end{itemize}

setup 最差路径从 \code{u\_cal\_fsm/state\_reg} 到 \code{cal\_done}：

WHS -0.147 ns；同类另有两个 target-index 端点，一条

register-to-register setup failure。

\begin{verdictbox}[title=\textbf{时序结论必须这样表述}]{Orange}
  100 MHz setup met，但完整 timing constraints \textbf{not met}，因为 hold
  有4个失败端点。当前报告不再只报 +0.298 ns。由于 top 的 I/O 形式本身不适合
  该 FPGA package，下一步应先加 prototype wrapper，再做 implementation、
  hold repair 和 post-route timing；ASIC 则必须用目标 standard-cell library、
  CTS、真实 I/O/clock budget 和 signoff STA。
\end{verdictbox}

0 unconstrained internal endpoints、0 missing input delay、0 missing output delay、
0 combinational loop。也就是说 hold failure 不是“忘了约束”，而是当前模型下
真实报告出的 endpoint failure。

\section{Verilog-A 工程：模块、方程、参数与验证限制}

\subsection{\code{cdac\_behavioral.va}}

模块包含 P/N 各14个 bottom-plate ports、top/bridge nodes、VINP/VINN 和
SAMPLE。默认 \code{CU=4 fF}、\code{VCM=0.9 V}、transition time 1 ps
只是行为参数，不是目标 PDK 签核值。

sample phase 只驱动 VTOP 到 VCM，bridge node 保持内部浮动并由电容分压。
conversion phase 对 P/N 两侧分别求解两节点矩阵。每个 high/low/bridge group
有独立 P/N multiplier port；模块不调用 RNG。

\subsection{\code{strongarm\_cmp.va}}

该模块是 clocked behavioral comparator，不是 transistor StrongArm。
默认参数包括：

\begin{itemize}
  \item base delay 0.5 ns、regeneration $\tau=50$ ps；
  \item logic swing 1.8 V、offset 0、noise 0；
  \item minimum differential 1 $\mu$V、maximum wait 10 ns；
  \item ready/result transition 10 ps。
\end{itemize}

rising clock edge 读取 \code{V(inp)-V(inn)}，可加输入等效 offset/noise，
delay 使用

\[
  t_d=t_0+\tau\ln
  \left(
    \frac{V_{\mathrm{logic}}}
    {\max(|V_{\mathrm{diff}}|,V_{\min})}
  \right)
\]

并限制最大等待。它适合验证 polarity、ready 和控制时序，不支持真实
kickback、input capacitance、PVT offset/noise、功耗或 metastability tail。

\subsection{AMS 闭环计划}

\begin{enumerate}
  \item 用 Python 同一 PER-UNIT seed 计算 realized group multipliers；
  \item 将 RTL switch buses 映射为模拟 rail switch；
  \item 比较 Python/VA 的 sampled charge、VTOP、VBR 和每 stage polarity；
  \item 用 \code{ready} 驱动或检查数字采样时刻；
  \item 重跑 ideal、nominal、stress 与关键 tail seeds；
  \item 再进入 transistor comparator、switch、reference 和 extracted CDAC。
\end{enumerate}

\begin{notebox}
  本机没有 Spectre/OpenVAF 可用编译器，所以本轮只完成源码结构与方程审查。
  这项限制不是“测试以后再说”的脚注，而是流片证据链中明确未闭合的一层。
\end{notebox}

\section{最终结论}

\begin{enumerate}
  \item 理想模型正确：\IdealCalSndr{} dB、0 missing、0 backstep；
  \item 失配是主退化源；physical oracle 证明阵列上限仍在，nominal decoder
    权重失配才是主要问题；
  \item 0.5\% PER-UNIT nominal 经 Q8 前景校准后 dynamic/static/combined
    100/100，说明整体性能已经稳住；
  \item 1.0\% stress 仍 dynamic 100/100、static 98/100、无缺码；不为两个
    轻微 INL 尾点过度设计；
  \item 0.3 mV 仅是 calibration-only decorrelation，用来解除 lower-SAR
    量化锁定，不代表 normal conversion 需要注噪；
  \item 局部 backstep 被完整量化：最大1 LSB、输入宽度窄；当前是诊断，
    不是架构重做触发器；
  \item RTL calibration subset 通过 XSIM 并可综合；setup proxy met，
    但 hold -0.147 ns、4端点和 IOB 273.6\%说明 FPGA wrapper/implementation
    仍需完成；
  \item Verilog-A 已具备合理方程和端口，但尚未 Spectre 编译；
  \item 当前方案逻辑上值得继续推进，距离 tapeout signoff 仍需 full RTL、
    AMS、PDK、transistor、reference、PVT、post-layout 与 ASIC STA。
\end{enumerate}

\begin{verdictbox}[title=\textbf{最终工程判断}]{Green}
  不需要围绕局部单调性继续“做梦式”扩张；应把下一阶段资源集中到真正缺失的
  full-ADC RTL、AMS trace、目标 PDK MOMCAP/开关/比较器、reference settling
  和 ASIC implementation signoff。当前 nominal mismatch-calibration 场景
  已达到行为级目标，报告同时保留 stress tail 与数字时序缺口，没有把不完整证据
  包装成流片完成。
\end{verdictbox}
