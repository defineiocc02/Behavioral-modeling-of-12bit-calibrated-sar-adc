# v3.0 figure archive

This directory is historical and is not used by the v3.1 report, CI, release
summary or reproduction path.

- `figures/` contains the v3.0 generated PNG/SVG/PDF assets and their manifest.
- `generator/` contains the matching historical generator.
- `RELEASE_RESULTS_V3.md` contains the matching historical release snapshot.

The active v3.1 figures are regenerated only from frozen Q8 mismatch evidence
into `docs/figures/mismatch_report/`. Keeping the old assets under an explicit
versioned archive prevents data from different releases being mixed.
